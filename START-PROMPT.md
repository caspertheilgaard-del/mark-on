# Første opgave til Claude Code

Kopiér teksten herunder ind i Claude Code, når repoet `caspertheilgaard-del/mark-on` er åbent og startpakken ligger i roden.

---

Læs CLAUDE.md og design/README.md. Byg grundlaget for MarkOns nye website i Astro ud fra designfilerne i design/pages:

1. Opsæt et Astro-projekt (statisk output) med CSS-variabler for farver, typografi og afstande fra CLAUDE.md, og Montserrat.
2. Lav de fælles komponenter: Topbar, Header med menu og mobilmenu (burger under 1100 px), Brødkrummer, Footer, Billedkort med pille, FAQ og "Hvor vil du hen nu?". Tag markup og værdier fra designfilerne.
3. Byg Julegaver først (design/pages/F-Julegaver.dc.html) på URL'en /firmajulegaver/, med teksterne i en content collection.
4. Kør `npm run build` og tag skærmbilleder af siden i 1440, 834 og 390 px bredde. Sammenlign med designfilen og ret forskelle.
5. Lav en branch og en pull request med skærmbillederne og en liste over, hvad der mangler. Merge ikke.

Spørg mig, før du afviger fra designet eller reglerne i CLAUDE.md.
